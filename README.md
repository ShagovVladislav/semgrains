# Semgrains

Локальная программа для сегментации зёрен на SEM-снимках. Поддерживает три метода обработки, измерение геометрии, сравнение промежуточных стадий, исправление масок, ручную разметку и пакетный экспорт. Работает на CPU, без нейросетей.

## Запуск

Нужны **Windows 10/11 x64**, Git и интернет при первом запуске.

Выполните в PowerShell:

```powershell
git clone https://github.com/ShagovVladislav/semgrains.git
cd semgrains
.\run.cmd
```

После клонирования также можно дважды открыть `run.cmd` в Проводнике. Скрипт скачает uv, Python 3.13.5 и закреплённые в `uv.lock` библиотеки, затем откроет приложение в браузере. Права администратора не нужны. Первая установка может занять несколько минут.

Загрузки идут с GitHub и PyPI. При ошибке соединения повторите запуск. uv и Python находятся в `.runtime`, библиотеки — в `.venv`; системные Python и PATH не меняются. Не закрывайте окно консоли во время работы. Остановка — Ctrl+C.

По умолчанию используется адрес `http://127.0.0.1:8501`. Если порт занят, выбирается следующий свободный; фактический адрес выводится в консоли.

Дополнительные варианты:

```powershell
.\run.cmd -SetupOnly
.\run.cmd -Offline
.\run.cmd -Port 8600 -NoBrowser
```

`-SetupOnly` устанавливает окружение без запуска интерфейса. `-Offline` работает после завершённой первой установки без обращения к сети. `-NoBrowser` отключает автоматическое открытие браузера.

## Работа с изображениями

1. Загрузите один или несколько PNG, TIFF, JPEG или BMP через левую панель. Встроенных снимков нет.
2. Проверьте границу служебной полосы. Диаметр 0 означает автоматическую оценку.
3. Если нужны физические единицы, укажите длину масштабной линейки в пикселях, значение подписи и подтвердите масштаб. Иначе измерения остаются в px.
4. Нажмите «Обработать снимок» и сравните тёмные границы, градиент и ансамбль. Для каждого метода доступны исходник, предобработка, карта границ, исходная/обработанная сегментация и наложение.
5. Выбирайте зёрна кликом: соседние можно объединить, ложные исключить, а одно зерно разделить линией через оба края. Исправления отменяются и сохраняются отдельно.
6. Во вкладке сохранения подготовьте ZIP. Пакетная обработка и ручная разметка доступны отдельными разделами.

Зёрна у края исключаются из количественной статистики и показаны оранжевым контуром. Автоматическую сегментацию необходимо проверять по исходнику, особенно при слабых границах и мелких зёрнах.

«Усиление слабых границ» включено по умолчанию; его можно отключить для сравнения результатов. Мелкие фрагменты со слабой границей присоединяются к соседней области без отверстий в маске.

В ZIP сохраняются стадии обработки, целочисленные маски TIFF, параметры JSON и таблицы CSV. Измерения включают площадь, периметр, центр, оси эквивалентного эллипса, эксцентриситет, эквивалентный диаметр, максимальный Фере и показатели границ. Автоматические и исправленные маски находятся в разных каталогах. Журнал исправлений можно сохранить в JSON и загрузить обратно.

Результаты записываются в `output`, собственная разметка — в `annotations/user`. Эти папки, окружение, загруженные инструменты и пользовательские данные исключены из Git.

## Пакетный запуск из консоли

После `.\run.cmd -SetupOnly`:

```powershell
.\.runtime\uv\uv.exe run --locked --no-sync python -m semgrains.cli batch --input "C:\SEM-images" --output "output\batch" --method all
```

Для одного метода задайте `--method dark`, `gradient` или `ensemble`. Опция `--config` принимает JSON с параметрами. Масштаб каждого файла можно передать через `--scales scales.json`:

```json
{"sample.tif": {"scale_length_px": 50, "scale_length_value": 200, "scale_unit": "nm"}}
```

Числа в примере условные: масштаб проверяется по конкретному снимку. Файлы без записи в карте масштабов измеряются в пикселях. Частичные ошибки записываются в `summary.csv`, остальные файлы продолжают обрабатываться.
